# User Feedback — Wishing Well

## How to reproduce

1. Open https://nyan-dev.github.io/wishing-well/
2. Scroll to see the well
3. Tap "Make a Wish", write a wish, submit
4. Click a floating boat to discover a wish

---

## Feedback

### User 1

- **Date:** 2026-07-30
- **Device:** Desktop Chrome
- **What worked:** The well looks like a real pixel-art game prop. Making a wish was intuitive.
- **What was confusing:** The "Make a Wish" button was hard to find at first (bottom-right corner).
- **Suggestion:** Add a subtle glow or pulse animation to draw attention to the button on first load.

### User 2

- **Date:** 2026-07-30
- **Device:** Mobile Safari
- **What worked:** The well scales nicely on mobile. Tapping boats to discover wishes is fun.
- **What was confusing:** The wish modal appeared but the textarea was small on mobile.
- **Suggestion:** Make the textarea taller on mobile so it's easier to type long wishes.

### User 3

- **Date:** 2026-07-30
- **Device:** Desktop Firefox
- **What worked:** The dithered water effect looks great. The wooden beam adds character.
- **What was confusing:** No feedback on what happens after submitting a wish.
- **Suggestion:** Show a brief "wish tossed!" confirmation before the modal closes.
